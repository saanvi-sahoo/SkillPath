# Study Strategies Guide

## Evidence-based learning techniques
Active recall (testing yourself instead of re-reading) and spaced repetition (reviewing at increasing intervals, e.g. with Anki) are the two most reliable techniques for long-term retention. Interleaving different problem types and explaining concepts in simple words (the Feynman technique) also improve understanding. Passive highlighting and re-reading feel productive but help little.

## Planning a study schedule
Break a skill into weekly milestones with a concrete output each week (a notebook, a mini project, a solved problem set). Use focused blocks such as the Pomodoro technique (25 minutes work, 5 minutes break). Reserve time every week for review of older topics. A realistic plan for a working student is 1-2 hours on weekdays and 3-4 hours on weekends.

## Learning by building projects
Employers value proof of skill. After learning fundamentals, build small end-to-end projects: clean a real dataset, analyse it, and publish a dashboard or write-up; or build and deploy a small web app or API. Put the code on GitHub with a clear README describing the problem, approach, results and how to run it.

## Choosing courses and certifications
Prefer one structured course per skill over many partial ones. Free options include YouTube playlists, freeCodeCamp, Kaggle Learn, Google and Microsoft learning paths, and audited Coursera courses. Certifications such as Google Data Analytics, Microsoft PL-300 (Power BI) or AWS Cloud Practitioner help most at entry level when paired with projects.
